## Experiments and supported alternatives

1. **Branch URL rejected.** Registering a GitHub `/tree/<branch>` URL failed
   because the service attempted to clone that literal URL. The tested package
   was then published through the repository's normal default branch and
   installed with auto-update disabled. Do not promise ref selection support.
2. **Native processing is terminal based.** The runtime has `RunInTerminal`,
   installed-file tools and `SaveFileToBlob`; it does not expose the older
   dedicated `ExecutePythonCode` tool. Terminal execution of the installed helper
   is the proven alternative. The existing manifest convention alone is not
   proof that a tool exists.
3. **Date-time formats can silently go unchecked.** Local tests and the runtime
   inspection both found jsonschema's optional `date-time` checker unavailable
   without another package. The helper registers the schema's explicit
   `utc-date-time` format using standard-library parsing and strict UTC syntax.
   Invalid dates are tested; this is full JSON Schema validation with a deliberate
   custom format, not a partial validator.
4. **Download links require thread context.** `SaveFileToBlob` produced a key
   containing the workspace path. The plain `/api/files/<key>` route returned
   HTTP 400. The app client normalizes it to
   `/api/files/<thread-id>/<key>`; the authenticated thread-scoped route returned
   the original bytes with the matching hash.
5. **MCP text omits structured execution fields.** `sreagent_threads_get`
   presented the Azure CLI execution as an empty text message. The raw existing
   `/api/v1/threads/<id>/messages` API supplied command, status and actual output.
   The read gate is based on that execution record, not the agent's "passed"
   narrative.
